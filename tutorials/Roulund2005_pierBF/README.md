# Roulund2005_pierBF: live-bed scour at a vertical pier (body-fitted bed)

The pier of `../Roulund2005_pierIB` with the bed as a deforming wall patch
instead of an immersed boundary: stock `pimpleFoam` with the `deformingBed`
function object of `libibScour` (Exner equation on the bed patch) and the
`displacementLayeredMotion` of every vertical mesh column between the bed and
the lid. The case is generated by `tests/bodyFittedPier/make_case.py`.

| Item | Setting |
|---|---|
| Mesh | O-grid around the pier, 128 cells around, 30 radial (first cell 2.2 mm), 45 layers (first cell 1 mm), Cartesian blocks outside |
| Bed | wall patch `bed`, van Driest wall law (k_s = 0.7 mm) as in the immersed case |
| Sediment | as in `Roulund2005_pierIB`, plus a bed-load adaptation length of 10 d50 |
| Time | 5 s of flow on the fixed bed, then morphological factor 2 to t = 155 s (300 s of morphological time) |

Run with `./Allrun` (`NP` ranks, default 48; about 6.5 h on 48 ranks); the
case is written to `./run` (or `RUN_DIR`). It reads the inflow profile of
`../Roulund2005_pierIB/constant/boundaryData/inlet`.
